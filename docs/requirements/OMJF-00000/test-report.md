## 修复记录

### 登录流程修复
- **问题**：ego-browser 使用 `input.value = 'xxx'` + `dispatchEvent('input')` 无法触发 Vue 3 的 v-model 响应式更新
- **修复**：改用 ego-browser 的 `fillInput('@ref', value)` API，通过 snapshot ref 定位元素，正确触发 Vue 响应式
- **验证**：登录成功跳转到 entry 页面，显示"欢迎回来，学生"
