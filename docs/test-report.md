## Bug 修复记录

### Bug 1：报告页答题数据丢失 ✓ 已修复
- **现象**：报告页得分显示 100 但所有题目标记 ✗，模块正确率 0%
- **根因**：使用 `uni.$emit`/`uni.$on` 跨页面传递答题数据，事件时序不可靠——报告页注册监听时测试页已发送完毕
- **修复**：改用 `uni.setStorageSync` 在跳转前存储答题数据，报告页同步读取
- **改动文件**：
  - `src/pages/test/index.vue`：`submitTest()` 中用 `uni.setStorageSync('lastTestResult', ...)` 替代 `uni.$emit`
  - `src/pages/report/index.vue`：在 `<script setup>` 顶层用 `uni.getStorageSync('lastTestResult')` 同步读取
